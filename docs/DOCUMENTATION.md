# Tula Documentation

The `docs` directory is where the documentation for the project is stored. The
purpose of this document is to define the different sections of the
documentation folder.


## Architecture Documentation
Located in the `docs/architecture` directory, it contains documentation about
the architecture and design of the project at a high level, without specific
code implementation knowledge or references.

Readers of this section of documentation should be able to understand the shape
and function of the project and it's parts at a high level without having to
understand or know the code and implementation of the project.

It is organized as a top-level design overview (`DESIGN.md`) that describes the
whole system and how its parts fit together, plus a dedicated document for each
individual part of the system.


## Guideline / Developer Documentation
Located in the `docs/guidelines` directory, it contains documentation about
the code of the project. Designed for developers to use when making
contributions to the project to understand implementation choices, coding style
/ conventions, and project layout.


## Language Documentation
Located in the `docs/language` directory, it contains documentation about the
language itself, designed for both technical users, and consumers, it provides
changes to the langauge over the various versions, as well as planned features
and demo documents which showcase the language in it's various versions.
